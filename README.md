\# SistemaRural-PE 

Sistema de software multiparadigma para la gestión de salud rural en el puesto de salud Marcabal Grande. 

## Estructura del Proyecto 

- \*\*Modelo\*\*: Clases de dominio en POO (\`Persona\`, \`Paciente\`, \`Medicamento\`, etc.). 
- \*\*Servicios\*\*: Procesamiento de colecciones con Java Streams (\`GestionPacientes.java\`).
- \*\*Excepciones\*\*: Control de errores personalizado (\`StockInsuficienteException.java\`). 
- \*\*Pruebas\*\*: Pruebas unitarias automatizadas con JUnit 5 (\`SistemaRuralPETest.java\`).
